# Huawei Modem Manager

Windows-приложение на Flutter для управления USB-модемом Huawei E173 через AT-команды и COM-порт.

## Что уже реализовано

- Автоматический поиск COM-портов Windows, чтение метаданных USB-устройств и проверка AT-ответа. Для Huawei приоритетен интерфейс **3G PC UI Interface** (в конфигурации E173 пользователя — COM22), а не общий Modem/Application Interface.
- Приоритет последнего успешно использованного COM-порта.
- Определение модели, IMEI, состояния SIM, регистрации сети, оператора и уровня сигнала.
- Ожидание регистрации SIM в сети.
- Ручной запуск сценария и автозапуск после регистрации в сети (один запуск на USB-сессию).
- Сценарий: USSD определения номера → USSD баланса → SMS на номер из настроек → повторный USSD баланса.
- Повтор USSD при ошибках, настраиваемые таймауты и ожидание сети.
- Отправка SMS в PDU-режиме с UCS-2 для кириллицы и разбиением длинных сообщений.
- Чтение SMS из памяти модема, удаление сообщения.
- Чтение и изменение телефонной книги SIM через `AT+CPBR` / `AT+CPBW`.
- Экран команд AT, журнал команд и ответов, SQLite-история операций и экспорт CSV.
- GitHub Actions для тестирования и сборки Windows Release ZIP.

## Требования

- Windows 10 или Windows 11 x64.
- Flutter stable и Dart версии, совместимой с `pubspec.yaml`.
- Для локальной сборки — Visual Studio 2022 с workload **Desktop development with C++**, CMake и Ninja (в GitHub Actions это предоставляется Windows runner).
- Драйвер Huawei E173 должен быть установлен так, чтобы Windows показывала его последовательные COM-порты.

## Быстрая сборка локально

Откройте PowerShell в корне проекта:

```powershell
flutter config --enable-windows-desktop
flutter create --platforms=windows --project-name=huawei_modem_manager --org=ru.huaweimodem .
flutter pub get
flutter test
flutter run -d windows
```

Для Release:

```powershell
flutter build windows --release
```

Если нужно создать только Windows runner, не перезаписывая файлы приложения, используйте скрипт `tool/create_windows_runner.ps1` из PowerShell. Он создаёт временный Flutter scaffold и копирует в проект только каталог `windows`.

## Сборка через GitHub

1. Создайте пустой GitHub-репозиторий.
2. Загрузите **содержимое** этой папки в корень репозитория, включая скрытые каталоги `.github` и `.gitignore`.
3. Откройте вкладку **Actions** и разрешите запуск GitHub Actions, если GitHub попросит.
4. Запустите workflow **Build Huawei Modem Manager (Windows)** через `Run workflow` либо сделайте `push` в `main` / `master`.
5. После успешной сборки откройте выполненный workflow и скачайте artifact `HuaweiModemManager-Windows-x64`.
6. Распакуйте ZIP и запустите `huawei_modem_manager.exe`.

В архив включаются исполняемый файл, Flutter runtime, плагины и папка `data`. Отдельно устанавливать Flutter на целевом компьютере не нужно. Драйвер Huawei E173 при этом должен быть установлен в Windows.

## Первичная настройка

1. Подключите E173 и дождитесь, пока Windows установит драйвер.
2. Откройте **Подключение** и нажмите «Обновить порты».
3. Нажмите «Подключить». Программа сначала проверяет Huawei **3G PC UI Interface**, затем остальные интерфейсы; для E173 это обычно правильный AT-порт. В конкретной конфигурации пользователя PC UI — COM22.
4. Откройте **Настройки**.
5. Укажите USSD-код определения номера, USSD-код баланса, номер SMS-получателя и текст сообщения.
6. Сначала выполните один ручной сценарий. После проверки корректности кодов включите автозапуск.

USSD-коды зависят от оператора и конкретной SIM-карты. В проекте `*100#` указан только как начальный пример для поля баланса; код определения номера не задан намеренно.

## Важные технические ограничения

- **Отправка SMS:** успешный ответ `+CMGS` означает, что модем принял сообщение к отправке. Это не является доказательством доставки адресату. Сетевой отчёт о доставке зависит от оператора, прошивки и настроек; программа явно показывает, что доставка не подтверждена.
- **Huawei E173 и голос:** голосовые звонки могут отсутствовать в конкретной модификации E173 или быть отключены прошивкой/оператором. Экран вызовов отправляет стандартные `ATD`, `ATH` и `AT+CLCC`, но не обещает голосовую совместимость.
- **Журнал вызовов:** стандартная `AT+CLCC` показывает текущие вызовы, а не историю завершённых звонков. История звонков не имитируется.
- **Контакты:** чтение, запись и удаление используют стандартные команды SIM-книги. Не все варианты прошивки разрешают изменение телефонной книги.
- **Сетевые данные:** точная технология сети, скорость и счётчики трафика могут быть недоступны через стандартный AT-набор этого модема. Программа не показывает вымышленные значения.
- **USSD-кодировка:** начальный DCS равен 15. При нечитаемом ответе попробуйте 72 в настройках — результат зависит от сети и прошивки модема.
- **Модем занят:** во время автоматического сценария фоновый мониторинг не посылает параллельные команды, чтобы не перемешивать ответы AT.

## Хранение данных

Настройки хранятся в локальных preferences Windows. История операций и журнал сохраняются в SQLite в каталоге Application Support текущего пользователя. CSV экспортируется в `Документы\HuaweiModemManager`.

## Безопасность

Проверьте USSD-команды у своего оператора до включения автозапуска. Не вставляйте в AT-терминал незнакомые команды записи, сброса или прошивки. Не используйте один и тот же модем параллельно в этой программе и в Huawei Mobile Partner/другом терминале: COM-порт обычно может быть открыт только одним приложением.
